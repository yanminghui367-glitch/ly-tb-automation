# 商品任务与标题草稿

## 当前能力

Step 3 将启用的国家和城市转换为独立商品草稿。首批数据默认生成 3 个国家级商品和 15 个城市级商品，共 18 件；每件商品生成两个确定性的规则标题候选。

管理入口：`http://127.0.0.1:8000/products`

当前标题只用于内部生产流程验证，**不代表已经符合淘宝规则，也不代表商品已经审核批准或可以发布**。

## 操作流程

1. 确认目的地页面中的国家和城市数据。
2. 进入“商品生产”，选择批次范围。
3. 首次建议使用“全部启用目的地”并保留“仅补缺失商品”。
4. 系统逐件创建任务并生成标题 A/B；一个任务失败不会回滚其他商品。
5. 在批次详情查看成功、复用、受保护和失败状态。
6. 对失败或中断任务人工重试一次；系统不会无限自动重试。
7. 打开单件商品，人工选择一个草稿标题。

重复提交相同范围、目的地、服务和规则版本时，系统使用输入指纹复用原批次，不重复创建商品、任务或候选标题。

## 商品与任务状态

商品当前主要使用：

- `DRAFT`：商品记录已建立，尚未生成标题。
- `GENERATING`：正在生成当前标题任务。
- `WAITING_REVIEW`：标题草稿已生成，等待人工处理。
- `VALIDATION_FAILED`：标题未通过内部草稿校验。
- `APPROVED` 及后续状态：为后续审核和发布阶段预留，普通重跑不得覆盖。

任务状态：

- `PENDING` / `RUNNING`：待执行或执行中；程序中断后可以继续。
- `SUCCEEDED`：本次生成成功。
- `REUSED`：相同输入已经成功生成，复用既有结果。
- `PROTECTED`：已有人工选择或批准内容，普通重跑没有覆盖。
- `FAILED`：本任务失败，可由运营人员人工重试。

选择标题只把 `title_review_status` 标记为 `SELECTED`，不进入完整商品 `APPROVED`。系统尚无可信用户身份，因此不会伪造审核人。

## 暂定标题规则

`PROVISIONAL_V1` 使用产品架构文档中的四个示例模板：

```text
城市 A：{城市}中文导游地陪翻译包车接送机一日游商务陪同服务
城市 B：{国家}{城市}旅游地陪中文导游翻译接送机包车定制服务
国家 A：{国家}旅游地陪中文导游翻译包车接送机定制服务
国家 B：{国家}当地导游地陪一日游商务陪同展会翻译服务
```

标题不使用 AI、随机数或当前时间。相同输入与相同规则版本会产生字节级一致的结果。规则版本一旦用于任务就不应原地修改；业务规则变化时新增版本。

内部暂定长度预算为 60 个显示单位，54 个单位开始预警；全角和中日韩字符按 2 个单位、其他字符按 1 个单位计算。该预算只用于尽早发现过长草稿，**不是淘宝当前标题上限的声明**。

## 业务确认门

进入标题确认、图片生产或人工发布验证前，需要补齐：

1. 每个国家和城市实际覆盖的服务，不应长期把全部八类服务视为真实承诺。
2. 最终标题模板、关键词顺序、品牌词、禁用措辞和特殊目的地名称规则。
3. 淘宝真实类目和标题计数方式、长度上限及禁用词，并记录一手证据和验证日期。
4. 两名操作人员的独立账号、审核权限和操作原因记录；开放私有网络访问前同时增加认证和 CSRF 防护。

在上述信息确认前，`product_services.coverage_status` 保持 `UNVERIFIED`，页面持续显示风险提示。

## 稳定错误码

- `NO_PRODUCT_TARGETS`：当前筛选范围没有缺失商品。
- `TITLE_RULE_NOT_FOUND` / `TITLE_RULE_INVALID`：标题规则缺失或配置损坏。
- `TITLE_VALIDATION_FAILED`：候选标题未通过内部草稿校验。
- `NON_DETERMINISTIC_TITLE_OUTPUT`：同一任务重跑产生不同内容，系统停止覆盖。
- `PRODUCT_CONTENT_PROTECTED`：商品已有人工选择或批准内容，普通重跑被阻止。
- `PRODUCT_VERSION_CONFLICT`：页面版本已过期，需要刷新后重新选择。
- `TITLE_CANDIDATE_NOT_CURRENT`：尝试选择其他商品或历史任务的候选标题。
- `UNEXPECTED_GENERATION_ERROR`：未预期错误，需结合本机日志检查。

## 数据与恢复

批次保存规范化输入快照和 SHA-256 指纹。每个商品任务使用独立短事务提交；成功的前置任务不会因后续失败而丢失。批次中断后，人工重试只处理 `PENDING`、中断的 `RUNNING` 和 `FAILED` 任务。

数据库迁移只向前执行。不得修改已经应用的 `0004_product_tasks.sql`；结构变化必须新增迁移。
