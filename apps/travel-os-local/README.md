## V2 自动上架引擎（2026-09-17）

新增独立命令行引擎：只读Excel适配、标准PublishTask、SQLite状态机、逐步回读校验、验证码checkpoint、提交结果核验及断点恢复。入口见 [V2运行说明](engine/v2/README.md)、[重构审计](docs/V2_REFACTOR_AUDIT.md)和[V2验收报告](docs/V2_P0_QA_2026-09-17.md)。当前已通过本地合成页面验证，真实淘宝单条发布及平台1/5/20/50压测尚未验收；旧工作台仍沿用下述DRY_RUN边界。

本项目是本地运行的旅游商品上架工作台。当前可用范围是：导入已生成的商品包、保存本地队列、管理独立 Chrome 会话、记录发布审核证据、配置经人工验证的字段映射，并将合格商品按映射填写到淘宝草稿提交前；任务会持续汇总风险、人工处理、草稿核验和可继续执行的下一步。
