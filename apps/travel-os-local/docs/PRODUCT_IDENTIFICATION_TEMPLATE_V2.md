# 星途商品识别模板 v2

**用途：** 为新建资料包建立统一的商品编号和素材文件名，让工作台按店铺、目的地、链接类型及素材版本精确匹配。适用于新录入资料；既有700条旧资料继续使用旧格式，不要批量改名。

## 商品清单

`商品清单` 共10列：`序号`、`国家或地区`、`城市`、`链接类型`、`标题一`、`标题二`、`使用标题`、`导购标题`、`售价`、`库存`。其中后两版标题和人工选择栏保留项目原有的双标题要求；序号是固定识别号，不随排序或换图改变。国家链接城市留空；城市链接必须填写城市，链接类型必须相符。

## 资料目录与图片命名

每个店铺一份资料目录，内部放 `商品资料.xlsx` 及 `主图`、`副图/A`、`副图/B`、`详情首页`、`详情正文` 五个目录。

- 店铺识别码：2至12位大写英文字母或数字，每个店铺独立且固定，例如五洲畅游可使用 `WZC`。此值需填入 `店铺设置`。
- 图片版本：每张图片单独带 `R01`、`R02` 等版本。首次使用 `R01`；只替换一张图片时，只递增那张图片的版本并移出该图旧版本。当前资料目录里同一素材编号只能有一个版本。不得覆盖旧图片或混放多个版本。
- 国家主图：`{店铺码}-{序号三位}-国家-{国家}-主图-{版本}.png`，例如 `WZC-001-国家-英国-主图-R01.png`。
- 城市主图：`{店铺码}-{序号三位}-城市-{国家}-{城市}-主图-{版本}.png`，例如 `WZC-002-城市-日本-东京-主图-R01.png`。
- 副图A：`{店铺码}-副图-A01` 至 `A04` 加版本；副图B同理。例如 `WZC-副图-B01-R01.png`。每套4张。
- 详情首页：`{店铺码}-详情页首页-1`、`-2` 加版本；详情正文：`{店铺码}-详情页正文-01` 起连续编号，共7至12张。
- 图片允许 PNG、JPG、JPEG、WEBP，但同一素材只能保留一个扩展名，不可因换扩展名造成同编号重复。

图片名称用于机械匹配，**不代表系统能从图片内容读出目的地**。主图画面、地名、国家/城市和服务资料仍须人工检查一致。错名、缺图、错类型或版本不一致会导致识别失败，不会自动猜测。

## 使用与适用边界

网站“资料设置 → 下载固定模板”提供该 v2 模板。旧版标准模板和旧资料仍可按旧规则识别。若切换店铺，复制空白模板目录，填写新店铺名称与识别码，并隔离保存该店铺的全部图片。

模板只整理资料，不填入未经核实的类目、价格、库存、物流或服务事实。模板导入成功不等于具备淘宝发布条件；新店铺仍须先完成执行适配。当前已验证的执行范围以项目状态和发布门槛记录为准。
