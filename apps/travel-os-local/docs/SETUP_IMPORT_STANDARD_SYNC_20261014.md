# 资料导入识别与商品资料标准同步

核验日期：2026-10-14。范围仅为资料设置中的标准 Excel 识别，不启动发布任务、不更改旧商品任务或执行状态。

用户提供的 `商品资料.xlsx` 使用现有 v2 的10列表头：`序号`、`国家或地区`、`城市`、`链接类型`、`标题一`、`标题二`、`使用标题`、`导购标题`、`售价`、`库存`。只读核对确认共700条：前200条为国家链接、后500条为城市链接，城市列均已填写。表头、工作表名称和链接类型已与局域网标准识别器一致。

发现一处固定选项的文字差异：这份表的“发货时效”填为 `按商品统一设置-24小时内发货`，识别器此前只接受 `24小时内发货`。现仅将这一个完整、精确选项归一为执行器已验证的 `24小时内发货`；其他不同文本仍需人工适配，不按局部关键词推断。商品解析、图片匹配和发布保护保持原规则。

验证：`workbench` 的 `npm run test:setup` 共22项通过，包括新加的当前固定选项识别回归。测试只使用隔离合成资料，无浏览器操作、无淘宝提交。

资料完整性边界：本次提供的表中700条的标题一、标题二、使用标题、导购标题均为空，店铺名称和店铺识别码也为空；当前附件只有 Excel，未包含主图、副图、详情页目录。因此它证明了资料表标准及城市字段格式，但尚不能直接作为完整商品资料包导入。需补齐实际店铺资料、标题和图片后，局域网才可完成资料包预检；预检通过仍不等于淘宝发布成功。
