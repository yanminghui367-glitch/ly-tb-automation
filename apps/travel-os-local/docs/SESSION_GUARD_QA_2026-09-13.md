## 初审发现与处置

1. 新浏览器上下文产生的页面未必触发原上下文监听。已反馈，后端增加确认页面集合及动态发现核验；独立“new context and tab”测试通过。
2. 恢复、人工填写确认、草稿完成入口仅核验任意已确认卖家页，未约束任务草稿地址。已修正：代码审查确认从当前待处理 item 取得任务映射草稿地址再执行 assertExecute；没有目标地址即拒绝。精确 URL 闸门由独立会话测试覆盖；本轮不使用真实任务数据执行这些 API。
3. 运行中暂停/取消未使会话闸门失效、并发 start 可重入。已修正：POST 互斥及每店铺执行互斥；忙时暂停/取消使核验立即失效，返回 409 明示当前动作后停止且需重试保存。独立 HTTP 测试和联合执行器并发测试通过。已进入浏览器的单个动作不能撤销，取消的持久化仍需操作者按提示重试。
