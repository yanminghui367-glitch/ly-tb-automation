# 发布随机规则 · 2026-10-04

状态：已实现，独立 QA 通过产品层与离线恢复验收；没有执行真实上架。

## 使用

1. 打开工作台 → **资料设置 → 发布随机规则 → 配置图片与属性**。
2. 从已配置的本地图片目录选择副图 A、B 两套，每套 4 张；用“上移”调整顺序。再选择两张详情首页候选。图片留在原目录。
3. 在项目执行 Chrome 中保留一个新增商品发布页，展开类目属性；点击“读取页面属性选项”。勾选允许随机的候选，确认素材与属性适用于商品后保存。品牌固定为“无品牌/无注册商标”。
4. 在任务中心创建新批次，或核对单商品准备单：展开图片预览，核对本次选择的副图套装、详情首页和属性，再生成任务。创建不会自动执行。

副图整套随机、详情首页独立随机；首页仅替换原详情列表第一张，不增加总张数。五项属性分别随机，允许连续抽到相同值。选择保存在预览草稿和最终任务快照，刷新、服务重启、失败重试沿用同一结果。

已有任务保持原快照；停用或更改规则只影响之后的新预览。候选素材内容改变、缺失、选项失效或页面无法确认时停止，不临时换图或换属性。验证码由用户手动处理，之后重新读取或从原任务恢复。

## 范围与边界

- 仅当前已适配的执行店铺提供配置与执行入口；配置按店铺 ID 保存。其他新增店铺的执行适配不在本轮范围。
- 属性取自实际页面，不将截图上的值写死。需要滚动、虚拟化或不能唯一归属的下拉列表会暂停，保留原错误供人工检查。
- 本地同名但内容不同的图片会阻止配置/预览；原图库选择器依赖文件名，平台历史同名图片的内容无法仅凭本地扫描证明一致。此处仍需要真实平台适配验证，不扩大本轮冻结文件修改范围。
- 本轮规则默认未启用，不替用户选择图片或确认适用属性。用户完成一次配置后才用于新任务。
- 当前真实店铺的新属性下拉适配尚未测试，不把合成页面测试当作淘宝通过记录。未新增任何真实任务、成功记录或发布授权。
