# 总览模板调整 · 2026-09-25

最新用户参考为圣托里尼横幅模板。现有运营工作台采用其布局，保留蓝色品牌、白底内容、点击固定侧栏和真实数据来源。

总览信息顺序：旅行横幅与目的地搜索 → 产品总数/已核验产品/执行中批次/待人工事项 → 国家目的地卡/店铺状态/最近批次 → 产品工作流入口/交互地球/最近执行记录。点击国家进入带筛选的目的地中心；搜索或点选地球后展开所选目的地详情。

指标口径：产品数按店铺导入的 catalogue 项计数；已核验产品仅统计 `state === VERIFIED`；执行中为当前引擎 active 批次数；待人工数来自引擎非 dataOnly 异常。任务进度为最近批次 SUCCEEDED / total，不等同平台成功率；记录列表按实际更新时间排序。未引入浏览量、转化率、增长率或虚构跨平台在线店铺。

新增 `workbench/overview.css` 仅应用于总览；现有全站字体、侧栏与其他模块保留。静态允许列表新增明确资源名称，不放宽目录访问。新增三张 AI 风景图仅用于 UI，原始用户参考不作为页面截图背景。

视觉与交互验收见根目录 `design-qa.md`，证据位于 `output/overview-template-20260925/`。本轮未执行真实上架。
