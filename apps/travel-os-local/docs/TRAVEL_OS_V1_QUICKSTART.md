# 星途 Travel OS · 本地使用

双击项目根目录的 `启动上架工作台.vbs`。打开原星途地球首页后，点击“打开工作台”进入八模块界面。页面左上角 Logo 和“返回星途首页”返回首页。

1. **店铺管理**：检查或打开项目专用 Chrome，人工登录。新店铺可随时添加；自动执行适配未完成时明确显示待适配。
2. **资料设置**：填写本机 Excel 与图片目录，保存并读取校验；也可打开原有 Excel/图片上传入口。源表不修改。
3. **选择目的地**：在总览搜索国家/城市，地球同步定位；查看产品和历史报价。堪萨斯城保持位置待确认。
4. **准备产品**：核对标题、主图/副图/详情顺序与原始售价库存，保存准备单。核对后可将支持的原店铺商品加入单项仅填写队列，不会自动提交。
5. **报价库**：选目的地，分别录入供应商成本价、对客销售价。修改报价通过新增历史记录完成，过期记录可归档。
6. **执行任务**：热度批次仍使用现有预览和确认流程。执行许可默认关闭；仅填写与正式发布明确区分。正式开始必须人工确认范围。
7. **异常介入**：在执行 Chrome 人工处理验证码，回工作台点击“已处理，检查并继续”。点击停止后等待“已暂停”和断点保存，不能把“正在暂停”当完成。
8. **查看记录**：平台 ID、实际状态、截图、来源批次与执行证据保留。出售中不表示仓库中；结果不明禁止重新发布。

当前边界：所选目的地入口仅 DRY_RUN；新增店铺发布需适配；无人值守自动重试未启用，失败任务仅支持检查后的有限重试。刷新页面不会启动任务，服务恢复后读取已有状态。

本轮没有增加真实上架数量。完整界面与恢复验证使用隔离数据库和模拟执行器。
