# 本地工作台 V1 · 日常操作

2026-09-23：启动后先显示“星途 Travel OS”目的地首页。可直接搜索城市查看资料与记录；“打开工作台”进入下列六模块操作，原地址 `/index.html` 继续可用。详见 [星途首页说明](TRAVEL_OS_HOME.md)。

1. 双击项目根目录 `启动上架工作台.vbs`，打开 http://127.0.0.1:4318/。当前电脑已安装独立依赖，正常使用不需要 Codex 或命令行；重复打开复用服务。
2. 点击“重新检查”。访问工作台的浏览器与执行上架的项目专用 Chrome 是两件事；需要登录时点“打开执行 Chrome”，人工完成登录。未知或过期状态显示“待检查”。
3. 在任务中心导入商品 Excel 和图片目录；已有本机路径可直接用，热度来源保留在高级项。原资料只读，上传使用项目内副本。
4. “识别并预览”后核对商品、价格、库存和全部素材。查看可执行、需补充、重复、已成功、已有任务分类。本批为热度顺序前 N 条合格商品，最多 20 条，没有“当前页/全部”隐含勾选。
5. 选执行模式并确认范围，再生成任务；生成不会开始。默认“仅检查首条”在提交前停止，**不能自动升级为正式批次**。真正上架须在生成时明确选择正式模式，并由操作者开启执行、确认范围后点击开始。本轮交付保持执行关闭，没有新增真实发布。
6. 在监控页看步骤、等待人工数与截图。关闭网页不停止任务；停止请点“暂停”。“正在暂停”表示当前步骤仍在结束/保存中；“已暂停”才表示运行停止且数据库已保存状态。结果不明单列为“待核验”，不重新提交。
7. 验证码在执行 Chrome 手动处理并保留原页面；点“已处理，检查并继续”。未通过恢复条件时会说明具体问题，不继续执行；无商品 ID 的结果不明任务须先在平台人工核对。
8. 上架记录可搜索、导出、查看批次/来源行和执行日志。成功商品按原有“店铺 + 国家/城市级别 + 国家 + 城市”标识防重，改标题或重复导入不会绕过。此规则针对本项目已知记录，不能推定覆盖所有历史手工发布。
9. 退出用系统设置“暂停并退出程序”；再次双击启动会恢复持久状态和专用 Chrome 登录。会话过期时仍需人工登录。

已知边界：伦敦源主图错配仍拦截；早期成功记录缺少完整快照时明确标注，不能补造原标题/时间/来源；暂停不是强制杀进程，当前页面操作可能需要结束后才能落定。高级资料路径与连接信息可在设置展开，凭证不展示或导出。
