# Step 3 候选

仅修改 taobao-publisher.mjs、listing-round.mjs 两个运行文件。详情阶段预算不动；attempts、max_attempts、extra_attempts 的业务语义和状态枚举不变。

主图点击只做一次，100ms 轮询，连续两次一致并达到目标前缀才返回；初始和点击后各5秒观察截止；点击后的等待及最终检查共享截止，不强行取消原guard。超时只产生 SAFE_RETRY_MAIN_IMAGE_STATE，稳定错误顺序仍拒绝。

普通提交前错误以 FAILED 终结后继续。同一商品多次恢复只计一个商品；同指纹连续3个不同商品或连续5个不同失败商品触发熔断。成功、人工跳过、预检跳过打断连续失败。计数来自持久事件，重启不清空。验证码、登录、未知提交、已提交证据、保留页、资料/身份变化及数据库/浏览器断链仍按原保护暂停。

已知代价：未分类 DOM 故障可能先失败3个商品才熔断。单条终态、队列、审计与计数在同一事务内；写入失败不假报继续。

同一现场的原3张图只读核验通过，0点击、0提交、数据库不变；2→3延迟由模拟及隔离原生DOM验证，不能声称已重新制造生产延迟。真实发布尚待安装后5条样本。

序号12现4/4、已用人工加额1次；统一上限实际是3次。用户批准修复验收后原任务再加1次至4/5，不重建、不改历史。原DRY_RUN也扣claim并在首条填表完成后停，因此不用它冒充免费五条验证。

本候选 manifest 的 deploymentAllowed=false 表示单独候选不自行部署。独立QA通过后，按用户本轮明确授权及安装现场条件维护；平台样本验收与候选验收分开。
