# 网站单条核验补齐

基于已安装 20261018-submit-receipt-r1，仅修改 round-item-verify.mjs。批量恢复已传原提交事件，但网站单条 VERIFY_ONLY 入口漏传，导致缺商品ID时仍报缺少原提交时间。现从原所属 SourceStore 读取事件，并使用既有 assertUnclaimedSubmissionId 检查，沿用既有只读后台核验与原子状态收口。

不修改提交次数、跳过条件、验证码或登录保护；查不到/冲突/证据不足仍保持待核验。按钮变为可继续的前提是原商品核验真正成功，不把“点击过核验”当成成功。

新增用例在旧代码确实失败，修复后通过；新用例贯穿单条控制器、RoundVerification、只读提交恢复与原run/queue/round原子同步，覆盖幂等重复请求与次数保持。独立QA及最终回归另附。

本候选不包含平台商品验收结论，不自动核验/跳过/恢复洪都拉斯或开始后续商品。
