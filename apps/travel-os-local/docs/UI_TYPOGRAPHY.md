# 全站字体规范 · 2026-09-25

## 目标与范围

旅游运营人员从地球首页进入工作台查找产品、检查任务与结果。首页需要有表现力的标题；工作台需要便于持续阅读的正文、可比较的数字与清晰状态。保留现有信息架构和功能，统一首页、八模块工作台、原版操作台与旧入口的字体层级。

## 实现

- 共享样式：`workbench/typography.css`，由四个 HTML 入口在现有样式之后加载。
- 中文与正文：本地 Noto Sans SC 可变字体，100–900 字重。数字采用 Segoe UI 与等宽数字特性。回退栈保留 Noto Sans SC、微软雅黑与 sans-serif。
- 字体来自本机 `C:/Windows/Fonts/NotoSansSC-VF.ttf`，无字形裁剪，仅转为 WOFF2；从 17,773,244 字节压缩至 7,783,400 字节。使用 `font-display:swap`，字体加载期间文字仍可读；页面不依赖外网字体服务。
- 字体元数据中的版权和许可保留于 `workbench/assets/fonts/NotoSansSC-NOTICE.txt`，完整 OFL 位于同目录 `OFL.txt`；来源 https://raw.githubusercontent.com/notofonts/noto-cjk/main/Sans/LICENSE 。
- 首页：800 字重主标题、700 字重城市名、14–17px 正文与简介；标题取消人工斜体，保留原有浅蓝视觉与背景。
- 工作台：30px/650 深蓝灰标题、20px/600 分区标题、14px 正文、13px 表格、12px 辅助说明；主标题不再大面积使用亮蓝色。蓝色保留在导航选中态与关键操作中。
- 手机：25px 工作台标题，输入框 16px；首页主标题按宽度缩放并允许换行。
- 状态标签仍保留已有语义色、文本及业务逻辑。
