# 上架记录页 UI｜2026-09-25

## 来源、范围与实现

来源：用户提供 `codex-clipboard-cf8a3a3c-fb22-4a3e-bf17-07e072c6c56e.png`（1672 × 941），先规划后明确回复“执行”。本页采用最新参考图的白蓝布局；既有全局导航、品牌、折叠行为和其他模块保留。适用入口 `/travel-os.html#records`，不覆盖历史深蓝截图结论。

- 四张统计卡、左侧真实店铺列表、右侧组合筛选和六列表格。
- 筛选：商品标题／目的地／平台 ID／原商品 key、执行结果、仓库核验、异常状态、完整本地日期范围。时间可升降序，每页 8 条。
- 搜索／状态筛选只影响表格；统计卡按店铺、日期及已有目的地入口范围汇总。待核验指 RESULT_UNKNOWN；异常含 FAILED、WAITING_HUMAN、PAUSED_CAPTCHA、RESULT_UNKNOWN，因此两项可能重叠。
- 历史结果与执行记录按 runId 合并，避免重复计数；成功与仓库独立，出售中显示“出售中 · 非仓库”。DRY_RUN_COMPLETE 不计发布成功。
- 导出使用与表格完全相同的筛选与排序，导出全部匹配行而非仅当前页。CSV 带 UTF-8 BOM、双引号转义与公式起始字符保护。
- 查看复用执行证据接口，并补充完整商品标题；无 runId 的历史行显示历史摘要，不编造执行日志。更多支持平台 ID 复制及已有商品链接；LAN 非安全上下文不能直接复制时提供手动复制编号。
- 使用真实本地商品主图；不可用时显示“暂无图片”。没有 AI 生图或替换商品事实。
- 1600px 以上桌面筛选单行；更窄桌面可换行。表格保持可读最小列宽并在自身容器滚动；850px 以下店铺使用选择器，统计卡两列。
