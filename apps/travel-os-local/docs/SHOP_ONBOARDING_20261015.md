# 新店铺标准资料接入与归属校验

2026-10-15。来源：用户要求将环球领航单店修复推广到后续同类型店铺，覆盖新增店铺、商品资料上传和执行对应关系。适用范围：本地星途 Travel OS，已登记且未移除的淘宝店铺，标准商品模板v1/v2和现有执行器支持的类目及字段。旧五洲资料和原任务保留原路径及快照；其他平台、类目或未核实业务条件不因此获得发布验收。

## 原因与修复

上一版独立存储已可用，但执行店铺仍使用两个ID的固定名单，新店不能直接进入资料流程；准备单可将一店商品配到另一店，后续执行才拒绝；部分商品总表详情与日志仍按网页URL的店铺请求。文件夹上传还会把归档和候选一起上传。这些都是本次通用接入要解决的缺口。

- `shop-execution.mjs` 取消特定店铺名单。有效ID还必须在注册表存在且未移除，才能得到独立的数据库、资料设置、上传记录、规则、任务和专用浏览器；新店不继承任何店的执行许可、Excel或素材路径。原五洲路径、环球路径均保持兼容。
- 新增店铺成功后网页直接进入该店资料设置。店铺管理和资料下拉对所有登记店提供同一路径。非原店仅显示标准资料格式，异类目或缺字段仍明确待补充。Excel店名不一致时提示实际名称和当前目标名称。
- 每个网页API请求显式带执行店铺；URL参数为空、重复或未知时拒绝。执行类接口核对正文shopId与执行店铺，上传初始化、续传及导入校验持久上传记录的shopId。店铺切换采用完整导航，不沿用旧表单或预览状态。
- 新导入记录增加 `sourceBinding`，保存店铺ID、名称、模板识别码和格式，原任务保留同一店铺ID；准备检查、预览和创建分别校验。准备单直接拒绝把A店商品配给B店；产品、素材缓存按店铺与导入版本读取，删除其他店铺回退读取路径。
- 商品总表内跨店查看详情、历史日志、前往资料设置和进入任务页均传递所选店铺。标准上传只收根目录 `商品资料.xlsx` 和主图、副图/A、副图/B、详情首页、详情正文中的直接图片；归档、嵌套候选及无关工作簿留在原处。

旧上传记录如没有店铺绑定，不猜测归属，提示在对应店铺重新选择资料。旧导入和运行快照不回写；新归属元数据仅附加于新导入。

## 后续使用

1. 在店铺管理添加真实平台店名，自动进入其资料设置。
2. 选择资料存放位置，引用主机标准资料或从当前电脑上传整套资料。
3. 核对Excel店名与网页目标一致，识别并保存；错误时按提示修正原资料或切换正确店铺。
4. 点击连接店铺，在其专用窗口登录，检查准备情况。
5. 在这家店的任务页核对商品、模式与范围，再按原发布门槛手动开始。
