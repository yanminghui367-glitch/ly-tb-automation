# 自动化规格｜P4 以后实施

## DRY_RUN

1. 启动指定店铺的本地 Chrome。
2. 检查登录状态；出现验证码或风控立即暂停。
3. 打开淘宝发布页，确认类目路径和必填字段仍匹配已审批字段映射。
4. 仅按用户商品包中已验证的 `automation_mapping` 填写标题、属性、价格/库存/物流、主图/副图、详情页；每一步截图和记录。映射不支持或字段缺失时暂停。
5. 在最终提交前停止，保存页面状态与日志。

## LIVE

仅在 `docs/RELEASE_GATES.md` 全部满足、且用户针对明确商品或批次授权后，才允许点击最终提交。成功标准是商品 ID 与商品链接被写入不可覆盖的结果记录。

不绕过验证码、滑块、风控、登录验证或平台限制。页面定位器失效、字段变化或上传结果异常时立即停止。执行器不包含发布或提交点击能力。
