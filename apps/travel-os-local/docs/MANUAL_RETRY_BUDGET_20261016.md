# 手动增加一次重试额度

日期：2026-10-16

## 规则

- 只从原轮次的重新检查结果中，为明确勾选的已失败商品增加额度。
- 每项只能增加一次；限制在原固定清单、原执行窗口和原资料快照。
- 服务再次检查执行是否停稳、提交证据、内容审核、队列状态及冻结文件。资料检查失败会明确拒绝，且不写额度或审计日志。
- 每项需填写操作原因并勾选确认。额度事件同时记入原批次和轮次；请求编号用于避免回执丢失时重复增加。
- 保存后只更新最大尝试次数。界面自动重新预检；创建重新检查和开始任务仍是独立操作，不会因增加额度而自动上架。

## 验收

- `node --check` 项目检查通过。
- `node --test` 聚焦集成回归：130/130 通过。
- `workbench/scripts/batch-recheck-ui-qa.mjs`：桌面/窄屏、重新预检、请求回执丢失、幂等恢复及不自动执行检查通过。
- 独立审查通过。新增反例覆盖预检后资料文件变化，确认返回确定失败，额度和双份审计均不变。
- 内核清单仍有3个本范围外文件漂移；因此虽已加载功能代码，网站全局完整性闸门仍关闭操作按钮。不得手工放开或将未审阅哈希写入清单。当前功能尚未达到可在正式网站使用的状态。

没有恢复批次、没有打开发布页或提交商品。
