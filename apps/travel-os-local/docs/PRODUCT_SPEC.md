# 产品规格｜P1

## 产品一句话

给淘宝境外旅游服务店铺使用的本地工作台：把用户提供的商品包变为可审、可追踪、可安全执行的发布任务。

## 用户与对象

- 主要用户：店铺运营人员。
- 商品：国家级或城市级旅游服务链接，不设 SKU。
- 商品包：标题版本、目的地、素材、类目字段、价格/物流、供给与审核证据的集合。
- 发布任务：一组经过审核的商品，包含顺序、模式、状态、日志和结果。
- 店铺会话：一个店铺对应一个本地 Chrome 会话，不保存密码或 Cookie。

## 核心页面

1. **首页驾驶舱**：店铺/Chrome 状态、待校验/待发布/执行中/成功/失败数；只突出“登录店铺、上传商品包、创建或查看发布任务”。
2. **商品包导入**：拖入文件或目录；显示结构、缺图、缺字段、重复、错误位置；不合格包不可入队。
3. **商品列表**：国家/城市、状态、两个标题、素材、字段完整度与重复风险；支持单条编辑和批量选择。
4. **商品预览**：以审核结构展示标题版本、目的地、素材顺序、商品包内类目/履约声明、文件预检与发布风险；审核结论可追溯，且不冒充淘宝商品页。
5. **发布任务中心**：选择商品、设置顺序与批量、DRY_RUN/REVIEW/LIVE 状态、暂停/继续/取消/重试。
6. **监督与反馈**：把任务按“需人工处理、等待草稿核验、可继续执行”归纳为下一步行动；显示人能看懂的原因、当前步骤、截图入口与恢复动作。
7. **设置**：店铺、Chrome、字段映射、图片规则、批量间隔、日志位置；未知淘宝字段必须显示为阻塞。

## 当前实现与目标差距

现有工作台已覆盖“首页、导入 READY/NEEDS_REVIEW JSON、店铺会话、审核证据阻塞、商品包预览、队列表格、字段映射、DRY_RUN 任务创建/排队/暂停/取消、本地监督反馈与 jobs.json 持久化”。待审核包可整理但不可创建执行任务；READY 仍需通过全部执行闸门。对已验证映射，执行器可填写、原生选择和上传，并在提交前暂停。它仍缺少真实淘宝字段验收、真实平台结果回写和 P5 单条发布验收；因此不把现状误称为自动发布。
