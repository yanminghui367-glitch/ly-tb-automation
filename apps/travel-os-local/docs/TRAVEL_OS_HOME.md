# 星途 Travel OS 首页

## 当前首页操作（2026-09-23 最新用户修正）

- 常用桌面窗口完整显示一屏。下面的旧版统计卡与“今天的工作”已从首页移除，请进入工作台查看任务、资料问题和记录；服务状态仍在页脚，人工验证/断点未保存的紧急提示仍会出现。
- 球下工具从左到右：全屏、放大、缩小、复位、**显示所有地址**（定位图标）、自动旋转。地址开关开启后随缩放聚合/展开；这里是已导入的城市中心及国家示意点，不是详细街道地址。
- 桌面放大地球后，球体自然延伸成为整页背景，搜索与城市卡片仍可操作，不再在中线截断。若只想看地球，点击全屏按钮；Esc 或“返回首页”退出。
- 手机仍按单列滚动展示完整内容，继续放大可进入地球全屏。堪萨斯城保持待确认，不在地图上猜测位置；完整 700 条目录仍能搜索。
- 最近查看与来源信息保留在“使用帮助”中；原素材、记录和任务入口不变。以下旧段落按历史增量保留，冲突处以本段为准。

2026-09-23，用户参考图与确认的“目的地首页连接实际商品”方案。

双击原 `启动上架工作台.vbs`，或访问 http://127.0.0.1:4318/。旧操作界面仍在 `/index.html`，原 `/#tasks` 等地址自动转到对应模块。页面左上品牌可返回星途首页。

1. 搜索国家、城市、商品标题或平台商品 ID，选择结果。
2. 城市卡片查看资料和原素材；显示上次导入检查结果，实际执行前仍需核对。
3. 已上架商品进入对应记录；已有任务进入原批次；资料问题打开详情处理。需要新建时，进入原任务中心按热度规则预览整批；点击城市本身不会生成任务或改变选品规则。
4. 点击“资料待补充”查看完整导入商品池的问题；不是本轮上架失败数。
5. 当前任务或验证码提示会置于首页上方。人工在执行 Chrome 完成验证，再进入原工作台检查并继续。

数据规则：只读最新商品池和最新热度导入快照，按原店铺/级别/国家/城市标识合并；热度快照覆盖同一商品的较早资料。数字不是固定展示文案。当前本地资料为 700 个目的地、30 条成功记录、30 个资料待补充商品；这些是当次检查值，后续以页面实际数据为准。旧热度异常区只覆盖热度任务范围，所以资料问题数量可能不同。

范围：新增 `travel-home.*`、`destination-catalog.mjs`、产品 API 只读查询、静态资源白名单与旧工作台入口适配。未更换框架、未改 10 个冻结内核文件、未新增真实发布。历史记录、源 Excel、商品图片和登录资料不因首页改造被修改。

2026-09-23 第二次增量：首页改为可拖动的 WebGL 球体。拖动旋转，滚轮/双指缩放，左侧按钮放大、缩小、复位和切换自动旋转；支持方向键与加减键。缩小时聚合目的地，放大逐级展开；点击聚合显示成员，点城市联动原商品卡片。“全部目的地”包含完整 700 条。699 条有位置，堪萨斯城按用户回复保留待确认。

地球使用本地 Three.js，读取了用户指定的 amap-jsapi skill 并采用其缩放分层、标注及资源释放原则；没有接入高德 JSAPI 服务，也不需要 Key。高德 3D 地图控制与自由观察整颗球体是不同展示形式。地理索引来源和 24 条同名推断见 `workbench/data/README.md`。国家标记为示意位置，城市标记为中心，不作为服务地址。装饰连接线不代表实际航班。

Logo 星形直接取自用户原图；原有业务导航、真实统计继续保留，不把参考图中的市场/免费试用/虚构数字做成可用功能。AI 城市图仅为品牌氛围，真实商品素材在资料弹窗中查看。无可靠匹配图或有错图问题时不将原素材用作目的地背景。没有接入实时市场洞察。

WebGL 不可用时显示明确提示，仍可用全部目的地和搜索；系统“减少动态效果”会关闭默认自动旋转。运行所需代码、贴图、坐标均在本机，不依赖外部地图在线接口。

验收：`output/travel-home-20260923/` 保存截图、产品测试和浏览器检查；根目录 `design-qa.md` 保存参考图对比结论，`.interface-design/system.md` 保存页面级设计扩展。

## 沉浸地球操作（2026-09-23 第三次增量）

- 输入完整目的地后按回车，地球与商品卡片同步定位。模糊搜索有多个结果时，先选择其中一项；未知地址不会凭空定位。搜索范围仍为已导入的 700 条资料，不是街道地址搜索服务。
- 拖动旋转，滚轮、双指或加减按钮平滑缩放；继续放大会展开到整个浏览器画面，也可点击左侧“全屏探索地球”。全屏只显示地球、位置和必要控制。
- 按 Esc 或右上角“返回首页”退出全屏，恢复之前的页面位置与操作焦点。不会更改商品、任务或执行状态。
- 堪萨斯城仍保留“位置待确认”，选中后停止之前的定位，不猜坐标。地图是城市中心/国家示意，云层和连接线为视觉呈现，不是实时天气或航班。
- 验证入口 `npm --prefix workbench run qa:globe`（开发用）；运营仍双击原一键启动入口。证据位于 `output/globe-premium-20260923/`，独立审核在其 `reviewer/` 子目录。
