# 新电脑简易使用｜2026-10-06

入口：打开星途 Travel OS → 打开工作台 → **资料设置**。页面顶部有“新电脑简易教程”。

## 首次使用：四步

1. **安装并选位置**：取得本版本完整项目，在项目目录双击 `安装工作台.cmd`；检查通过后双击 `启动上架工作台.vbs`。进入资料设置，选择主机上的资料目录，例如 `D:\TravelOS资料`。已有主机资料可以直接引用，无需复制。
2. **导入资料**：下载固定模板，解压后填写 `商品资料.xlsx`、放好图片。资料已在主机时选该文件夹；资料在访问电脑时选“从当前电脑上传”。点击“识别并保存资料”，按明确的行号、文件名处理缺项。
3. **连接店铺**：只用“连接店铺”按钮，在运行工作台的电脑上打开的专用 Chrome 中人工登录。等待显示目标店铺已登录；验证码也在该窗口处理。
4. **检查后核对任务**：点击“检查准备情况”，失败原因直接展示。通过后到自动化任务核对商品；需要执行时，在第4步的“发布随机规则与执行许可”中设置许可，再手动开始批次。检查本身不会创建任务或发布。

安装器的 Node.js、Python、Chrome 与依赖要求见 [安装与迁移说明](GITHUB_INSTALL_MIGRATION_20261001.md)。本轮不自动同步 GitHub，旧下载包不会因为本机更新而变成新版。

## 模板只整理一次

一个店铺一个文件夹。保留模板表头及工作表名称；商品表每条填写国家、城市、两版标题、选择标题、导购标题、售价、库存。店铺设置填写实际核实的类目、采购地、物流等信息；不要为消除报错填写不真实的值。

```text
店铺资料/
  商品资料.xlsx
  主图/           主图-001.png、主图-002.png……（对应商品序号）
  副图/A/         副图-A01.png ～ 副图-A04.png
  副图/B/         副图-B01.png ～ 副图-B04.png
  详情首页/       首页-01.png、首页-02.png
  详情正文/       详情-01.png 起，连续编号7～12张
```

图片支持 PNG/JPG/JPEG/WebP，每个文件不超过16MB。同一编号只保留一个格式，文件名不要重复。没有随机规则时默认使用副图A与首页01；若要随机，导入后在第4步展开“发布随机规则与执行许可”，核对两套图片和允许的属性，再保存。随机选择在新任务预览后固定，旧任务不变。详情正文可以共用，但必须适用于对应商品，不得包含错目的地内容或未经核实的承诺。

旧资料不用改成新模板。选择“原有 Excel（兼容已有资料）”，引用原热度表、商品表和图片目录即可。

## 日常只做三件事

**换资料 → 检查准备情况 → 核对任务并确认执行。**

- 同一套资料未变化时，无需重复上传、设置目录或登录；状态变化按页面提示处理。
- 上传的图片写入选定主机目录下的“导入批次”。目录不可用会报错，不自动转存C盘。设置、任务数据库等小型运行文件仍位于项目运行目录。
- 上传不会自动搬走或删除旧图片；已有冻结任务还引用旧目录，保留旧资料直到相关任务结束。
- 导入总数是全量商品数；单批预览最多20条是执行范围，不是丢失资料。
- 已有任务恢复沿用原快照；遇到“待核验”先核验原商品，不能重新提交。

## 另一台电脑只访问局域网网站

只访问主机的局域网地址时，无需再装一套。主机必须开机并启动工作台；资料上传保存到主机所选目录，店铺登录也在主机执行 Chrome 完成。局域网 IP 可能变化，以主机当前地址为准。

新电脑独立运行则执行上方四步，自行登录，不复制浏览器配置或凭证。此指南不宣称已经完成第二台实体电脑现场验收。
