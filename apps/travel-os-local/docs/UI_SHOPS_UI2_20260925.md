# UI-2 店铺管理页

日期：2026-09-25。来源：本任务用户提供的店铺管理参考图、确认后的方案及“执行”指令。适用范围：`/travel-os.html#shops`，界面实现与本地自验，不代表多店铺发布验收。

## 实现

- 在原页面增加四张统计卡、名称/系统编号搜索、状态筛选、排序、10/20/50 条分页及八列表格；沿用折叠导航与本地中文字体。
- 样式限定在 `#page-shops`，蓝色主操作、浅蓝次级操作。850px 以下转为两列统计及店铺卡片。
- 数据使用原 `/api/os/state`；当前编号是系统店铺编号，不宣称淘宝平台 ID。正常登录与需要登录分开统计，未知、过期、断线均不算正常登录。没有月度历史对比数字。
- 产品与任务入口、新增店铺、移除确认及原任务保护继续复用。浏览器按钮提示在服务主机打开；不是局域网客户端上的远程浏览器。
- 中文输入法组合期间不重绘搜索框；筛选分页独立于其他模块。
- 修改范围：`workbench/travel-os.js` 的店铺呈现及对应事件，`workbench/travel-os.css` 的店铺作用域，`workbench/travel-os.html` 的资源版本。共享文件中的并行任务/产品/目的地修改保留，不归入本次成果。

## 联调与限制

并行任务页新增资源被旧服务拒绝，导致共享入口脚本不能加载；检查 active=null 后通过原退出接口重启服务，加载更新后的静态白名单。未改他人资源内容，未启动或继续发布。

本记录是实现者自验，不冒称独立 QA 放行。截图使用真实已有店铺数量，因此不会补造参考图的三家店铺。平板宽度表格可在容器内横向滚动；手机转换为卡片。多店铺自动执行能力沿用既有边界。
