## 2026-10-13 资料设置误报“执行浏览器未运行”已修复

原因已确认：资料设置页复用了 2026-10-07 保存的旧检查报告（`stale=false` 未把浏览器状态纳入指纹），其店铺连接项记为“未运行”；当时执行浏览器状态已经是 `running=true, loggedIn=true`。第3步的“下一步，检查准备情况”原先只切换页面、不执行检查，因此旧错误持续显示。

修复：第3步“下一步，检查准备情况”现在会调用正式准备检查接口、刷新店铺状态并展示新报告；用户也可以在第4步直接点“检查准备情况”复核。已通过隔离浏览器 17 项资料设置验收；局域网提供的新脚本返回 HTTP 200 / `Cache-Control: no-store`。通过同一网站检查接口刷新后，店铺连接报告为 `ok=true`、`已登录`。没有启动或恢复上架任务。

资料：`workbench/setup-ui.js` 与 `workbench/scripts/setup-ui-qa.mjs`。更改只涉及连接状态报告刷新路径。
