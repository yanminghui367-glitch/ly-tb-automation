# 工作台白色主题与折叠导航（2026-09-25）

## 范围与依据

用户明确指定蓝色品牌、白色工作台背景与 Aceternity Sidebar 风格的可展开导航。本次仅调整 `/travel-os.html` 的 HTML、CSS 与导航表现，不改变首页、业务接口、商品数据或发布闸门。

## 产品认知与设计选择

- 用户：旅游商品运营人员；业务对象：店铺、商品资料、目的地、报价、执行批次、上架结果。
- 使用路径：地球首页 → 工作台 → 选择模块 → 核对当前资料或执行状态 → 操作与核验。
- 首要判断：当前处理哪个目的地/任务，是否存在需要人工处理的问题。
- 成功标准：八个模块都能到达，折叠后仍可识别图标，手机上能切换模块，状态语义和操作保持可读。
- 恢复路径：断线提示与重新连接、原有异常处理入口、抽屉关闭按钮与 Escape。
- 保留：原生 HTML/CSS/JS、真实业务内容、现有模块、状态提示和表格；替换：深色金色主题及固定宽度导航。
- 视觉：白底、深色正文、蓝色强调、细分隔线；成功/警告/错误仍用带文字的绿/黄/红标签。
- 参考：ui-ux 的运营工作台质量门、ui-ux-pro-max 的对比度/触屏/焦点/减少动态规则，以及 https://ui.aceternity.com/components/sidebar 。
- 技能检索给出了营销页和大标题建议，与现有操作台及用户指定白底不匹配，因此只采用适用的可访问性建议，不引入营销布局或新框架。

- 桌面默认 76px 图标栏，展开为 248px；仅点击 Logo 右侧按钮切换状态，悬停与模块切换不改变展开状态（按本日后续用户要求更新）。Logo 链接返回首页。

- 850px 以下使用导航抽屉；打开时背景不可聚焦，Tab 保留在抽屉内，Escape 关闭，选择模块后关闭。
- 图标链接保留可访问名称与标题；当前模块有蓝色选中态；系统减少动态时取消侧栏动画。
