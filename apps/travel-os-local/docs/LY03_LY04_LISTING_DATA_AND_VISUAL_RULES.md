# LY｜03 国家城市与服务数据库＋LY｜04 主图副图与视觉生产｜业务规则输入

更新日期：2026-09-12。信息来源：项目负责人本轮确认。本文将业务意图与已核验的平台事实区分记录；标记为“待页面核验”或“待供给核验”的内容不得直接用于真实发布。

## 1. 首批链接规模与类目

- 规模：每店 700 条链接；后续增加店铺。
- 项目负责人指定的目标类目：`个性定制/设计服务/DIY >> 其它定制 >> 其它商品定制`。
- 状态：**待页面核验**。真实卖家后台的类目路径、全部必填/可选属性、字数和素材要求必须在目标店铺当前页面确认并记录，不能只以本文或历史截图推定。

## 2. 服务、目的地与标题规则

### 服务类型池

包车、翻译、地陪、地接、一日游、导游、接送机。

每个服务类型只有在对应目的地确有可履约供给、价格、退款规则与所需资质时，才能进入某个商品包；随机选择不得制造不存在的服务承诺。

### 标题

- 标题目标：60 字符 / 30 字。该表述存在“字符、汉字及平台计数方式”的歧义，须在真实类目页面复核后固化为机器校验规则。
- 国家级链接：`国家 + 服务内容`。
- 城市级链接：`城市 + 国家 + 服务内容`。
- 服务内容可从服务类型池选择并调整词序，但标题必须与目的地、实际服务、主图和详情一致。
- 每条商品仍保留两个标题候选版本；实际使用版本、计算长度与生成来源需要记录。

## 3. 价格、库存与属性

- 价格候选：20、50、100；一个店铺在一个批次内统一使用其中一个价格。具体选择必须由店铺配置明确保存，不能在执行时随机变价。
- 库存目标：99999。状态：**待供给/履约核验**。只有服务方能够支持相应承接能力、且平台允许该填写方式时才可使用；不能将虚构库存写入商品。
- 属性：项目负责人要求随机化。执行定义只能是：从已在目标类目页面核验、且与该商品事实相符的“允许值库”中选取。不得对材质、规格、适用对象、服务承诺等字段填写随机或不真实内容。

## 4. 主图、副图与详情页规则

- 每条链接使用统一视觉模板，但背景与目的地不同。
- 主图／副图候选：每条商品有两套素材候选，执行时可从通过校验的套装中选择一套。每套仍必须满足主图、4 张副图、目的地一致性、顺序和去重规则。
- 详情页：首页有两版候选，可随机选择已审核版本；其余详情页使用一套固定内容。
- 所有被选择的素材版本、背景、目的地、详情首页版本、哈希和本地路径必须冻结至商品包和任务快照，以便审计和恢复。

## 5. AI 生图模块授权与受控规则

项目负责人已明确允许新增 AI 生图模块。生图模块只服务于每条商品的两套候选主图／副图素材，不替代商品供给、服务描述、目的地事实或平台字段核验。

- 每套生成素材必须绑定商品、目的地、服务类型、视觉模板和生成版本；禁止跨目的地错用。
- 生成前后均须检查版权、商标、人物肖像、地标/景区标识、夸大服务承诺和平台图片规格风险。
- 通过校验的两套素材才能进入商品包；未审核或校验失败素材不得自动上传。
- 需要继续确定：视觉模板来源、每张图片规格、审核责任人、验收标准、素材归档位置和失败重生策略。

## 6. 700 条正式数据集的最低字段

每条链接至少需有：店铺、链接级别（国家/城市）、国家、城市（如适用）、服务类型、两个标题候选、选定标题、店铺统一价格、经核验的属性值、库存依据、主图与 4 张副图的两套候选、详情首页两版及固定其余详情、供给/资质/退款履约证据、线上重复核对、商品包版本。

在上述字段未齐全前，条目状态只能是 `NEEDS_REVIEW`，不能创建真实发布任务。

## 7. 合规自动化边界

目标可以是“资料齐备后自动连续处理 700 条”，可采用授权店铺的正常浏览器会话与合规 RPA/浏览器自动化。不得绕过登录、验证码、滑块、风控或其他平台安全控制；遇到这些情形必须暂停、记录原因并等待合法的人工处理后再继续。
