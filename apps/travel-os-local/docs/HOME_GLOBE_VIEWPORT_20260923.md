# 首页整页地球 · 2026-09-23 增量验收

【当前阶段】P2 首页局部改进。继承原夜景视觉，落实用户连续三次修正；不新增业务模块。

【本轮目标】去除球体上的统计遮挡、提高清晰度与地理辨识；桌面一屏显示；新增所有地址开关；放大球体作为整页背景，去除左右分栏裁切边界。

【检查到的现状】原生 HTML/CSS/JS + 本地 Three.js 0.186.0；此前球体仍受左侧 canvas 宽度裁切。运营摘要造成首页下滚。源目录 700 条，其中 699 条有位置，堪萨斯城仍待确认。
