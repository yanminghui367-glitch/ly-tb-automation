# 导购标题焦点超时局部修复｜2026-10-13

## 现象

原700批次的“卢布林”任务在 `guide-title` 暂停。页面日志确认标题输入已有冻结任务中的导购标题值，但 `locator.press("Tab")` 超时；原截图显示主图操作菜单仍打开。该证据支持菜单覆盖/焦点残留为高可能原因，但未在原页面中以人工操作完成因果验证。

## 修复

`taobao-publisher.mjs` 在主图选择循环后加入一个受保护步骤：只查找官方主图操作菜单 `ul[role="menu"].sell-component-material-item-media-operator`；仅当四项菜单文本严格匹配“裁剪、替换、删除、AI 作图”时发送 Escape，等待该菜单消失并再次检查原身份/验证码守卫。其它菜单、变化后的菜单或不能关闭的菜单均失败关闭，不会继续填写或提交。

任务数据、图片顺序、执行范围、标题内容、类目、价格、库存、提交按钮和发布规则均未改。新增单元用隔离 Chromium 覆盖精准菜单、变化菜单和无菜单情形。
