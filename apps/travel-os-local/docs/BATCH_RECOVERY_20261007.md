## 使用方法

1. 刷新工作台，进入“自动化任务”。创建批次可选100条；核对清单后创建，仍需单独确认开始。
2. 原异常批次使用“重试异常链接”，显示并核对具体商品。每条沿用原任务、素材、随机结果与尝试上限。
3. 再遇执行异常立即停止；检查原因后人工重试，不能通过“继续”越过失败。达到3次后需明确人工跳过或保留异常，不无限重试。
4. 重试成功后，若仍有原待上架商品，重新确认“继续”；验证码或待核验状态从原任务恢复，不重新发布。
