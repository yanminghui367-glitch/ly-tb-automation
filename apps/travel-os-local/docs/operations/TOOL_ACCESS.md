1. 沿用本地工作台和文件知识库；不部署 RAG 服务或额外任务平台。
2. ComfyUI 仅按 2026-09-12 清单记录为后端候选，其服务、模型、磁盘和 GPU 状态本轮未复测；不作为当前可调用生产工具。

4. Codex 侧栏对话创建、读取、发送接口本轮未发现；用步骤卡与当前任务协作记录代替，不能虚构对话链接或历史阅读结果。
5. 禁止通过工具收集、导出或写入明文密码/Cookie/敏感凭证，禁止绕过风控；截图和日志分享前核查敏感内容。
