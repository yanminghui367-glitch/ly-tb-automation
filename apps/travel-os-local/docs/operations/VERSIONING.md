日期：2026-09-13。管理版本：standardization-v1。版本标签只标识管理基线，不代表平台上线版。

## 基线范围

本轮建立本地Git提交，采用显式文件清单纳入自有工作台源码/样式/模板、tools脚本、文档、启动入口及已审核的本轮聚合测试证据。Git实际提交哈希在本地 `git log -1 --oneline` 可查；本轮验证清单位于 `output/standardization-20260913/`。

`.runtime`、浏览器配置、Cookie、调试会话、node_modules、第三方归档、原始商品包/图片和一般运行输出排除。既有输出引用仍需本机原目录存在；本基线不能单独重建真实商品资料或登录态。依赖以现有package.json为准，本轮不生成新锁文件或安装依赖，不承诺跨机器依赖完全复现。

## 每轮版本动作

1. 查看Git状态和任务归属，明确可编辑文件；已有变更不得重置。
2. 记录改动目的、输入证据、验收和未覆盖风险；按 [QA标准](QA_STANDARD.md) 检查。
3. 只暂存本轮指定文件；复核路径和可能的秘密值，不用 `git add .` 纳入运行数据。
4. 在 `codex/` 分支做本地提交并核对提交内容。无用户身份配置时使用明确代理身份，不伪造用户姓名。
5. 失败修复以新提交记录。回退优先对指定提交做revert；不要对共享未提交现场执行hard reset或批量清理。回退前检查未提交内容和依赖，必要时先保存。

本轮不推送远端、不部署、不删除旧资料。远端备份与异机恢复尚未验证；本地Git不等于异机备份。
