# 第 15 步｜成败指标与取数规则

版本：1.0；日期：2026-09-13。本文件定义未来如何测量，并记录一次本地队列快照；不建立仪表盘、不宣称业务收入或平台成绩。

## 统计合同

- 所有记录包含统计时间（Asia/Shanghai，原始日志可 UTC）、店铺、批次 ID、商品 ID、目的地类型、包 SHA-256、映射指纹、代码版本、指标定义版本及来源路径。
- 一个店铺＋国家/城市层级＋目的地是商品粒度；一次尝试另有 attempt_id。重试不能重复计成功链接，也不能删除失败样本；同名城市须有国家信息。
- 运行队列快照以本次全部 100 条保存记录为分母，不代表计划 700 条已全部导入。READY 标签与当前强校验合格分别统计。
- 周期指标按批次启动时冻结清单；统计截止仍暂停或失败的条目保留在分母。取消仅单列，不能事后缩小分母美化成绩。
- 分母为 0 填 `N/A（无样本）`；未采集填 `未测`；未知不是 0。只对同店、同口径、可比商品复杂度和版本的周期进行对比，变更时分组报告。

## 采集与复盘

1. 批次开始前由总负责人冻结样本清单和口径；QA 核对来源与版本，缺少字段先标未测。
2. 执行岗逐次记录尝试、工时、暂停和结果；敏感凭证不进入记录。
3. QA 每批核对平台结果与任务结果，报告分子/分母/缺失数，优先指出护栏触发。
4. 总负责人每周比较同口径基线，决定修缺项、保持规模或扩大；没有手工基线不下提效结论。

未纳入主要指标的候选：生成图片数、工具/代理数、脚本次数不能代表交付；浏览量/GMV不能证明上架正确；利润与个人留存现金需要真实订单、履约、退款和成本数据，此步不具备数据，不能宣称该项目已带来收益。若后续评价商业收益，另立有真实账目来源的利润口径。
