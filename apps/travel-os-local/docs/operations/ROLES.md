# 岗位与交接规则｜第 7 步

日期：2026-09-13。状态：岗位制度已建立；不是新增常驻代理或创建侧栏对话的证明。

## 责任与执行方式

用户是业务事实、供给与最终发布范围的负责人；LY｜00 是项目协调负责人。每个任务指定一名执行者和一名复核者，执行者不得自签发布放行。可以由同一个协作系统承担多个岗位，但制作和 QA 必须分开执行、留下独立复核记录；未实际安排复核者就标为待复核。

用户已授权本项目访问、发送、编辑、查看、总结和按步骤协作。本轮使用当前任务内协作代理与步骤卡承接工作；没有可调用的 Codex 项目对话管理接口，不能宣称已创建或接管历史对话。岗位名称不代表现有对话已被读取或已收到消息。

## 岗位分工

| 岗位 | 输入 → 输出 | 可写范围与禁止动作 | 交接及验收责任 |
| --- | --- | --- | --- |
| LY｜00 项目总负责人 | 目标、状态、证据、冲突 → 单轮范围、优先级、决策、派工 | 项目制度/状态/任务；不能代签 QA 或补造业务事实 | 接收各岗结果；LY11 复核重要交付；业务争议交用户 |
| LY｜01 信息源调研（本轮定义） | 明确问题、允许渠道 → 带日期/来源/适用范围的资料及不确定项 | 资料目录；不修改商品供给、价格或发布状态 | 交 LY02 归档、LY03 业务映射；LY11 检查引用 |
| LY｜02 知识库 | 原始资料、历史产出、复盘 → 资料/经验/结论索引 | docs/knowledge；不得把旧结论改标为当前实测 | 交提问岗位；LY00 处理相互冲突的结论 |
| LY｜03 国家城市与服务数据库 | 经核验业务资料、标题池 → 一国/一城一链接的数据、双标题、缺项表 | 指定数据副本；不推断供给、属性、库存或线上去重结果 | 交 LY04、LY07；LY11 检查数据与证据对应 |
| LY｜04 主图副图与视觉生产 | 目的地、服务事实、模板、规格 → 最多两套候选素材及审核表 | 新版本候选目录；未审核素材不得进正式包 | 交人工素材审核及 LY07；LY11 复核数量、顺序、一致性 |
| LY｜05 商品预览与内容复核（本轮补全） | 商品包、标题、素材 → 内容差异和人工选择记录 | 预览/审核副本；不得代填虚构人工审核人 | 交 LY07 修订或 LY11 复验 |
| LY｜06 浏览器填写执行（本轮补全） | 审核包、店铺确认、映射、DRY_RUN 任务 → 提交前截图/动作日志/暂停记录 | 仅已准入任务；不能绕过风险或最终提交 | 交 LY11 核验；登录/验证码交人工 |
| LY｜07 商品包自动化生成 | 指定源包/数据、已审核素材 → NEEDS_REVIEW 副本、预检报告、版本 | 指定新输出目录；不覆盖源包、不自动写运行队列 | 交 LY05/LY11；用现有契约和生成器验收 |
| LY｜08 淘宝自动化上架引擎 | 已确认缺陷、映射契约 → 小范围代码修改、回归证据 | 指定代码与测试；不改发布模式规避门槛 | 交 LY11 独立复验，与 LY10 协作会话问题 |
| LY｜09 发布准入与恢复规则（本轮补全） | 审核问题、恢复证据、阶段条件 → 闸门修订建议、恢复规则 | 发布规范；无权单方批准 LIVE | 交 LY00 决策、LY11 独立审核 |
| LY｜10 浏览器账号与登录态 | 专用会话、人工店铺确认 → 会话归属、失效/风险处理证据 | 会话检查记录；不读取导出凭证，不把 CDP 连通等同登录 | 交 LY06 执行、LY08 修复、LY11 验收 |
| LY｜11 质量验收与发布审核 | 交付版本、标准、证据 → 通过/拒绝/待证据及复验要求 | QA 报告；不得同时修改被测对象后无记录自审 | 交 LY00 汇总；发布仍需相应业务范围授权和阶段条件 |

依据：现有 LY00、LY03/04、LY07、LY08、LY10、LY11 专项文档及外部组件清单。LY01、05、06、09 名称是本轮补全的责任定义；没有可核实的旧岗位全名时不伪称沿用原对话标题。

## 一次交接必须留下的五项

1. 任务 ID、步骤、执行者、复核者（未指派写待指派）及允许写的文件。
2. 输入版本/哈希与事实来源，指出未经证实内容。
3. 交付路径、完成内容及明确未做的部分。
4. 验收命令/检查项、实际结果、证据路径及证据限制。
5. 卡点、下游接收岗位、一个下一步；范围有变化先由 LY00 更新任务，再继续。

不得并行改同一文件；先交接再修改共同入口。知识检索不能解决登录、真实供给、当前页面或未授权范围时，保留阻塞，不以历史资料替代事实。
