# LY｜00 项目总负责人｜项目章程

更新日期：2026-09-12。信息来源：项目负责人本轮确认。本文是业务目标与授权边界的记录；未知业务事实不得因本章程而被推定为已确认。

## 1. 项目背景

为境外旅游服务店铺批量上架、发布商品链接，服务具有包车、翻译、地陪、地接、一日游、导游、接送机等需求的客户。

## 2. 一句话最终目标

为境外旅游服务店铺上架并发布链接。

## 3. 首期交付目标

在商品资料齐备的前提下，单店完成 700 个具有一定差异化的境外旅游服务链接上架；流程应可持续自动运行至批次结束，无需人工逐条监督。

“资料齐备”至少包含真实且已核验的类目/属性、供给与资质、价格/退款/履约、目的地与素材、以及当期淘宝页面字段映射。该定义用于避免把本地文件齐全误判为可上架。

## 4. 项目范围与非目标

- 范围：只做境外旅游服务商品的上架发布自动化，以及支撑该过程的商品包、素材、审核、任务、浏览器会话、日志和工作台。
- 约束：淘宝侧没有 API；不得绕过登录、验证码、风控或平台规则。
- 非目标：不做与商品上架发布无关的无效内容；不凭空生成未被供给和素材支持的服务承诺。
- 素材原则：允许新增受控 AI 生图模块。每个商品最多生成两套候选素材；只有通过目的地、服务内容、版权/商标/人物/地标风险及平台规格校验的素材，才可进入商品包。

## 5. 授权与责任

项目负责人确认：本项目具有商品发布业务授权。

该授权不替代每条商品资料的真实性核验、平台规则、店铺身份确认、线上重复链接核对和异常处理。系统可在已核验的授权范围内自动运行；登录失效、验证码、风控、页面结构变化、字段或资料不一致时必须暂停并留下记录，不得尝试规避。

## 6. 当前优先级

- 首个规模：每店 700 个链接。
- 店铺数量：后续增加。
- 国家、城市、链接标题及主图/副图素材：以项目的“国家城市和链接主图副图”资料为业务来源，待逐条纳入正式数据库与商品包。
- 服务类型：包车、翻译、地陪、地接、一日游、导游、接送机等境外旅游服务；具体目的地、履约范围、价格与资质必须在商品包内确认。

## 7. 成功指标

1. 资料齐备且复核通过后，系统可自主完成单店 700 条链接的上架流程至批次结束。
2. 有可查看商品资料、审核状态、任务进度、异常、证据与结果的统一工作台。
3. 自动化上架稳定：每一条的执行、暂停、恢复、失败隔离和最终结果均可追溯；不能以任务“完成”替代淘宝商品 ID/链接结果。

## 8. 当前待总负责人继续定义

1. “一定差异化”的可验收规则：标题、主副图、详情、服务组合、目的地或其他维度分别允许怎样变化，哪些内容不得变化。
2. 700 条的国家/城市/服务类型分配与同店线上去重规则。
3. 发布完成的判定：是否以淘宝返回商品 ID 与商品链接为唯一成功依据。
4. 自动运行的异常策略：风险、验证码、登录失效或资料不一致时由谁处理、多久恢复、何时隔离或终止批次。
5. 首家店铺、真实旅游服务类目、全量必填属性和供给/资质资料来源。

## 9. 与现有阶段规则的衔接

本章程把“无人逐条监督、700 条稳定上架”确认为产品目标。现有 P4/P5/P6 规则仍要求先取得一条真实商品的页面填写、暂停恢复和成功结果证据，再扩大为批次自动运行；这是为验证稳定性和平台兼容性，不是对业务授权的否定。后续应由 LY｜09 将首次单条验收与 700 条批量准入条件统一写明。
