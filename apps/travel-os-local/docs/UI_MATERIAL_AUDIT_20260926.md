# 产品库待补资料自查 · 2026-09-26

用户要求到已知资料目录核查待补项，并在待补资料页增加“重新检索”，区分真实空缺与对应问题。

## 实现

- 产品库“待补资料”标签增加资料自查区、重新检索按钮、时间和逐项证据。
- 使用已配置商品表/热度表/素材目录，以及当前店铺商品的原导入快照。扫描整个配置图片目录的文件名，但只核查当前店铺待补商品的关联文件。
- 区分文件缺失、原路径失效但找到同名候选、已知错图指纹、重复国家/城市映射、文件哈希变更、无法完成检查、需人工复核。候选结果明确仅按文件名匹配，不能当作内容核验通过。
- 热度重复对应显示来源行、排名、原表英文名称/机场/坐标等可用字段，帮助人工消歧。
- 原资料只读。仅将诊断结果持久化到 `.runtime/material-audits/`；不导入、不修改问题标记、不更新商品素材或队列、不运行发布动作。
- GET 读取上次报告；POST 仅接受店铺标识，拒绝客户端指定路径，拒绝未知/已删除店铺；执行中拒绝检索。重复请求复用进行中的扫描。
- 目录或导入版本变化标注旧报告；源表扫描中变动给出警告。失败可重试，断线禁用按钮，390px 无文档横向溢出。

主要文件：`tools/rescan_materials.py`、`workbench/material-audit.mjs`、`workbench/travel-os-api.mjs`、`workbench/travel-os.js`、`workbench/travel-os.css`。
