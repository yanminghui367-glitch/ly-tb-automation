# 旅行上架工作台

双击根目录的 `打开旅行上架工作台.cmd`。它会启动一个仅绑定本机 `127.0.0.1:4318` 的本地服务，并打开工作台页面。

## 当前已实现

1. 支持拖入 JSON、选择多个 JSON、选择整个文件夹或同步本机路径；接受 `READY` 和 `NEEDS_REVIEW` 商品包，待审核包可整理预览，但不能创建执行任务。READY 也须经过商品、证据和映射复核。
2. 每个店铺启动独立可见的 Chrome，并通过本机专属调试端口连接；登录配置只放在该电脑的 `workbench/.runtime` 下。
3. 队列支持搜索、勾选、批量预检与店铺不匹配拦截；从队列打开千牛后台、记录当前链接的准备状态。
4. 不会复制 Cookie，不会处理验证码，也不会自动点击最终发布。

## 两台电脑部署

每台电脑安装 Node.js 24+ 与 Google Chrome，然后在 `workbench` 文件夹执行一次 `npm install`。迁移已审核的代码和必要商品素材；不要复制 `.runtime`、浏览器配置或调试会话，第二台电脑应自行登录每个店铺。当前版本和排除范围见 `../docs/operations/VERSIONING.md`。

## 多店铺

点击“添加店铺”，填写店铺名称和可选登录提示。工作台会为它建立独立 Chrome 会话，已登录店铺可并存。淘宝密码只在淘宝登录页由操作者输入，不由工作台保存、读取或自动填充。
